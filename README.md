# @sxedward/koishi-plugin-waifu-draw

Koishi v4 抽老婆插件：发送命令随机抽取一位老婆，显示**名字、情缘（1%~100%，只取整数）和对应照片**；每位用户可以查询自己的收藏进度；管理员可在控制台面板或聊天命令中维护老婆名单、照片、CD 和次数限制。

## 安装

在 Koishi 控制台的插件市场安装，或执行：

```bash
koishi add sxedward/waifu-draw
# 或
npm i @sxedward/koishi-plugin-waifu-draw
```

要求 Koishi `^4.18.0`。不需要数据库，也不需要额外图片服务；用户数据以 JSON 文件形式保存在插件数据目录。

## 照片存放位置与命名规则（重要）

- **默认目录**：Koishi **应用目录**下的 `data/waifu-draw/photos/`（即 `koishi.yml` 所在目录下的 `data/waifu-draw/photos/`）。
  - 应用目录位置示例：模板项目为项目根目录；启动器 zip 版为解压目录下的 `data/instances/default/`；启动器 msi 版为 `%APPDATA%/Koishi/Desktop/data/instances/default/`。
  - 插件首次加载时会自动创建该目录。
- **可在面板修改**：控制台 → 插件配置 → 抽老婆 → `照片存放目录`。可填相对应用目录的路径（默认 `data/waifu-draw/photos`），也可填绝对路径。
- **命名规则**：
  1. 推荐把照片命名为 `<老婆名字>.<扩展名>`，例如老婆名字填 `小红`，照片命名为 `小红.jpg`；面板中“照片”字段就填 `小红.jpg`。
  2. 支持扩展名：`jpg`、`jpeg`、`png`、`webp`、`gif`、`bmp`（发送时按扩展名设置 MIME 类型）。
  3. “照片”字段也可以是**相对应用目录的路径**（如 `data/waifu-draw/photos/小红.png`）、**绝对路径**，或 `http(s)://` 图片链接；不带路径分隔符的纯文件名会按上面的照片目录解析。
  4. 照片文件请放在插件数据目录内，随 Koishi 应用目录一起备份；插件不会把照片上传或发到外部服务，只在抽中时读取并发送给用户。
  5. 单张照片上限 12 MB；文件缺失、为空或过大时仍会发送名字和情缘，并附带一条简短的缺失提示。
- **用户数据文件**：`data/waifu-draw/users.json`（按 `平台:用户ID` 记录累计情缘、累计次数、冷却与当日次数）。删除该文件会清空所有用户的抽取记录。
- **名单数据文件**：`data/waifu-draw/wives.json`（管理员用聊天命令增删的名单结果）。插件加载时：若面板名单未变化，沿用命令维护的名单；若面板名单发生变化，则以面板名单为准并覆盖该文件。

## 控制台面板设置

| 配置项 | 说明 |
| --- | --- |
| 管理员名单 | 可填 QQ 号（如 `123456`）或 `platform:userId`（如 `onebot:123456`）。列表中的用户可查看名单并使用添加 / 删除命令；Koishi 权限等级 4 及以上的用户同样可以。 |
| 老婆名单 | 表格形式，每行包含 **名字** 和 **照片** 两个字段。增加一行即新增一位可抽取老婆，删除一行即从抽取池中移除（不会清除用户已有的抽取记录）。此处的名单是初始名单；命令增删的结果保存在 `wives.json`，面板名单一旦变化，重载时会以面板为准。 |
| 照片存放目录 | 见上节。修改后请把照片放到新目录，或同步修改名单里的照片值。 |
| 抽老婆冷却时间 | 单位秒，按用户计算，默认 10 秒；`0` 表示不限制。 |
| 每日抽取次数 | 每位用户每个自然日（00:00 重置）最多抽取次数，默认 20 次；`0` 表示不限制。 |
| 抽中时发送照片 | 默认开启；关闭后只发送文字。 |

> 修改面板配置后 Koishi 会自动重载插件，无需重启（照片本身不会随配置自动复制，需自行放入目录）。请避免同时用面板和命令维护名单；以其中一种方式为准，避免被覆盖。

## 命令

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `抽老婆` | `waifu.draw` | 随机抽一位老婆，显示名字、本次情缘（1%~100% 整数）、累计情缘、累计次数和照片；受 CD 与每日次数限制。 |
| `老婆统计` | `waifu.stats`、`我的老婆` | 一次查询：已有老婆数量、已有数量占名单总量的百分比（保留两位小数）、累计情缘前 7 名及情缘、累计次数前 7 名及次数。 |
| `老婆名单` | `waifu.list` | 仅管理员可用，查看当前名单、照片文件名和照片目录。 |
| `老婆添加 <名字> [照片]` | `waifu.add` | 仅管理员可用。按文件名 / 相对路径 / http(s) 链接登记照片；不填照片但在消息中附带图片时，会自动保存到照片目录，命名为 `<名字>.<扩展名>`（重名加 `-2` 等后缀）。 |
| `老婆删除 <名字> [-k]` | `waifu.remove` | 仅管理员可用。从名单移除，并默认删除插件照片目录内的对应照片文件；加 `-k` / `--keep` 只移出名单、保留文件。http(s) 链接和目录外的照片不会被删。 |

示例：

```text
用户：抽老婆
Bot：抽到了：小红
    情缘：87%（本次，1%~100% 整数）
    累计情缘：350%　累计次数：4 次
    [图片]

用户：老婆统计
Bot：【老婆统计】
    老婆数量：3 / 10
    已有占比：30.00%（小数保留两位）
    累计抽取：12 次

    累计情缘 TOP7：
    1. 小红　350%
    2. 小美　201%
    ...

    累计次数 TOP7：
    1. 小红　4 次
    2. 小美　3 次
    ...
```

管理员命令示例：

```text
管理员：老婆添加 小美 小美.jpg
Bot：已添加老婆“小美”，照片：小美.jpg
     当前共 3 位。

管理员：老婆添加 小丽        ← 同时附带一张图片
Bot：已添加老婆“小丽”，照片：小丽.png
     当前共 4 位。

管理员：老婆删除 小美
Bot：已删除老婆“小美”，并已删除对应照片文件
     当前共 3 位。

管理员：老婆删除 小丽 -k
Bot：已删除老婆“小丽”（已保留照片文件）
     当前共 2 位。
```

> 自动保存的图片支持 `jpg/jpeg/png/webp/gif/bmp`，单张不超过 12 MB；支持消息中的 base64 图片和 http(s) 图片链接。命令改动即时写入 `wives.json`，重启后仍然有效。

### 数值口径

- **本次情缘**：每次抽中随机产生 `1~100` 的整数百分比。
- **累计情缘**：同一位老婆多次抽中时，本次情缘相加，因此可能超过 100%；TOP7 按该值排序。
- **已有占比**：`已抽中过的老婆种类数 ÷ 当前名单总数 × 100%`，保留两位小数。删除名单条目会改变分母。
- 统计仅针对发起命令的用户，不同平台 / 用户 ID 的数据互相隔离。
